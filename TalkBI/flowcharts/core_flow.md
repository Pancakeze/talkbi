```mermaid
flowchart TD
    A[业务人员进入 TalkBI] --> B{选择数据范围}
    B -->|选择已有主题库| C[选定主题库 (如: 交通流量)]
    B -->|上传新数据| D[上传 Excel 文件]
    D --> E[后台构建临时表并联合查询]
    E --> C
    
    C --> F[在对话框输入自然语言问题]
    F --> G[私有化大模型解析意图]
    G --> H{是否能理解并匹配字段?}
    
    H -->|是| I[生成 SQL 并在限定库内执行]
    I --> J{执行是否成功?}
    
    J -->|是| K[返回数据结果并推荐图表类型]
    K --> L[前端渲染图表及数据逻辑面板]
    
    L --> M{用户操作}
    M -->|满意| N[保存到个人图表库 / 组装仪表盘]
    M -->|修改视觉| O[切换图表类型/颜色/标题]
    M -->|修改逻辑| P[调整维度/度量/筛选条件]
    O --> L
    P --> I
    
    H -->|否| Q[返回异常提示: 字段未找到或意图不明]
    J -->|否| Q
    
    Q --> R{连续失败次数 >= 10次?}
    R -->|否| S[引导用户换种说法重试]
    S --> F
    R -->|是| T[提示: AI无法解决, 建议联系管理员]
    T --> U[用户点击'联系管理员']
    U --> V[打包对话上下文生成后台排查工单]
```
